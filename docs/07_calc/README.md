# 计算器

基础四则运算计算器，5×4 按钮网格。

## 功能概述

- 四则运算 + 百分比
- C 清空、< 退格
- 顶部表达式显示栏

## 按键布局

```
┌───┬───┬───┬───┐
│ C │ < │ % │ / │
├───┼───┼───┼───┤
│ 7 │ 8 │ 9 │ * │
├───┼───┼───┼───┤
│ 4 │ 5 │ 6 │ - │
├───┼───┼───┼───┤
│ 1 │ 2 │ 3 │ + │
├───┴───┼───┼───┤
│   0   │ . │ = │
└───────┴───┴───┘
```

## 颜色方案

| 类型 | 色值 | 说明 |
|---|---|---|
| 数字键 | `0x334466` | 深蓝 |
| 运算符 | `0x0F3460` | 更深蓝 |
| 功能键 | `0x2C3E50` | 灰蓝 |
| 等号 | `0x00E676` | 亮绿 |
