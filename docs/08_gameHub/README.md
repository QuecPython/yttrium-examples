# 游戏 Hub

本章讲解 Demo 中的游戏 Hub，包含 **贪吃蛇**、**2048**、**俄罗斯方块** 三款经典游戏，通过二级页面统一入口访问。

## 功能概述

Game Hub 是一个二级导航页面，展示 3 个游戏图标，点击进入对应游戏：

| 游戏 | 说明 |
|---|---|
| Snake | 贪吃蛇，34×20 网格，触摸滑动操控 |
| 2048 | 经典 2048，4×4 网格，滑动合并 |
| Tetris | 俄罗斯方块，10×20 网格，触摸操控 |

## 导航架构

```
主屏幕 → Game Hub（二级页面）
              ├── Snake  → 贪吃蛇
              ├── 2048   → 2048
              └── Tetris → 俄罗斯方块
```

## 各游戏详解

### 1. 贪吃蛇（Snake）

![贪吃蛇](images/snake-game.png)

| 参数 | 值 |
|---|---|
| 网格 | 34 列 × 20 行 |
| 单元格 | 14×14 px |
| 初始速度 | 150ms/帧 |
| 操控 | 触摸滑动（上下左右） |

颜色方案：

| 元素 | 颜色码 | 颜色 |
|---|---|---|
| 空白 | `0x16213E` | 深蓝 |
| 蛇头 | `0x00E676` | 亮绿 |
| 蛇身 | `0x4CAF50` | 草绿 |
| 食物 | `0xFF5252` | 红色 |

核心逻辑：
- 触摸滑动识别方向（上下左右），禁止 180° 反向
- 吃到食物 → 蛇身 +1，分数 +10，重新生成食物
- 撞墙 / 撞自己 → 游戏结束，显示 Game Over
- 速度随分数递增，越来越快

```python
# 方向向量
DIRS = {
    'up':    (0, -1),
    'down':  (0, 1),
    'left':  (-1, 0),
    'right': (1, 0),
}
# 每帧更新
head = (head_x + dx, head_y + dy)
if head == food:
    snake.append(head)  # 吃到食物，尾巴不动
else:
    snake.pop(0)        # 移除尾巴
    snake.append(head)  # 添加新头
```

### 2. 2048

| 参数 | 值 |
|---|---|
| 网格 | 4×4 |
| 单元格 | 48×48 px |
| 间距 | 4 px |
| 操控 | 触摸滑动（上下左右） |

方块配色：

| 数值 | 背景色 | 文字色 |
|---|---|---|
| 2 | `0x334466` | 白 |
| 4 | `0x3D5A80` | 白 |
| 8 | `0xE07020` | 白 |
| 16 | `0xE85D20` | 白 |
| 32 | `0xE84420` | 白 |
| 64 | `0xE82C20` | 白 |
| 128 | `0xEDCF72` | 黑 |
| 256 | `0xEDCC61` | 黑 |
| 512 | `0xEDC850` | 黑 |
| 1024 | `0xEDC53F` | 黑 |
| 2048 | `0xEDC22E` | 黑 |

核心逻辑：
- 滑动方向所有方块靠边，相邻相同数值合并
- 每次滑动后随机生成 2（90%）或 4（10%）
- 合并得分累加，同时记录最高分
- 无可用移动 → 游戏结束

### 3. 俄罗斯方块（Tetris）

| 参数 | 值 |
|---|---|
| 网格 | 10 列 × 20 行 |
| 单元格 | 14×14 px |
| 初始速度 | 500ms/帧 |
| 操控 | 触摸：左右滑动平移 / 向下滑动加速 / 点击旋转 |

7 种方块及颜色：

| 方块 | 形状 | 颜色 |
|---|---|---|
| I | ████ | 青 `0x00BCD4` |
| O | 2×2 方块 | 黄 `0xFFEB3B` |
| T | T 形 | 紫 `0x9C27B0` |
| S | S 形 | 绿 `0x4CAF50` |
| Z | Z 形 | 红 `0xFF5252` |
| L | L 形 | 橙 `0xFF9800` |
| J | J 形 | 蓝 `0x2196F3` |

消行计分：

| 消除行数 | 得分 |
|---|---|
| 1 | 100 |
| 2 | 300 |
| 3 | 500 |
| 4 | 800 |

核心逻辑：
- 方块自动下落（lv.timer 驱动）
- 触摸滑动 → 平移 / 旋转 / 加速下落
- 满行消除 → 上方行下移 → 累加得分
- 方块堆到顶部 → 游戏结束
- 右侧显示下一个方块预览 + 当前得分

## 通用代码结构

三个游戏共享相同架构：

```
GamePage(AppPage)
├── 游戏容器（lv.obj，深色背景）
├── 网格单元（lv.obj 矩阵，颜色切换）
├── 分数显示（lv.label）
├── 触摸事件（lv.EVENT.ALL → 方向/旋转识别）
├── 游戏循环（lv.timer 驱动帧更新）
└── _on_back() → 回到 Game Hub
```
